# 📋 Lista de Tarefas

Este é um projeto simples de uma **Lista de Tarefas interativa** desenvolvido com **HTML, CSS e JavaScript (jQuery)**. O objetivo é praticar manipulação de elementos na página, eventos e animações básicas usando jQuery.

---

## 🚀 Funcionalidades

- Adicionar novas tarefas por meio de um formulário dinâmico
- Listar tarefas adicionadas na página
- Marcar tarefas como concluídas clicando nelas (texto riscado)
- Mostrar e esconder o formulário de inserção com animação de slide

---

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript com jQuery 3.7.1
- Fonte Roboto do Google Fonts
